## How to obtain each group

- **Dataset and released weights.** Request access through the form linked from the SICKLE repository README (github.com/Depanshu-Sani/SICKLE), then unzip `weights.zip` and point `SICKLE_RUNS` at its `runs/wacv_2024` folder. Compare checksums with the CSV.
- **Ladder, sweep and interrupted runs.** Retrain with the committed configs (`configs/`) and `scripts/train.py` (the full sets: `scripts/run_ladder_py.py`, `scripts/run_sweep.py`); each run's `manifest.json`, `config_resolved.json`, `trainlog.json` and `best.json` are committed and record the seed, commit and settings. Retrained weights will not be bit-identical (GPU nondeterminism), so their checksums will differ; the committed per-run metrics are the reference to compare against.
